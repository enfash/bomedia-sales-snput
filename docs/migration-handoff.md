## Bookkeeping period (11 Oct, local only; migration `202610110033_bookkeeping_period.sql`)
- Owner decisions: only **month-ends** can be chosen, and closing is **permanent** (no reopen button; the existing ledger guard already refuses to move `closed_through` back, so no business logic changed). Design canvas "BOMedia Bookkeeping Period" approved 11 Oct.

The browser sends only `requestId` and `through`; the identity is the server's `SUPABASE_ADMIN_STAFF_ID`. `FinancialError` now turns the database text "This accounting period is closed" into "That date is in a closed bookkeeping period. Ask the owner." for every write path.
